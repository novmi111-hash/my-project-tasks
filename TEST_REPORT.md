## Непроверенные условия

- Нативная установка и холодный запуск в Obsidian, реальная боковая панель и восстановление вкладки.
- Реальный YAML-движок Obsidian: тестовый адаптер использует JSON как подмножество YAML; в поставляемом коде используются parseYaml/stringifyYaml из Obsidian.
- Визуальное отображение в реальных светлой и темной темах, пользовательские CSS-сниппеты, доступность с экранным диктором.
- Android, iOS и отдельные версии настольных операционных систем.
- Одновременное редактирование/завершение одной серии на разных синхронизируемых устройствах.

Обязательная нативная проверка перед публичным распространением: установить в копию хранилища, открыть через значок и команду, создать/изменить/завершить/восстановить задачу, проверить повторение и смену дня, перезапустить Obsidian, сверить Markdown-файлы и резервные копии, проверить обе темы и узкую панель. Для мобильной публикации отдельно проверить меню карточки и сенсорные операции.

## Инженерные решения

Запись через Vault.process сравнивает текущее содержимое с прочитанным, чтобы не затирать внешние правки. Служебная отметка незавершенной операции позволяет повторить создание продолжения после сбоя. Перед первым изменением каждого файла сохраняется исходный текст. Настройки прежних списков и неизвестные свойства не удаляются.

API ориентиры: официальная документация Vault (https://docs.obsidian.md/Plugins/Vault) и определения публичного API (https://github.com/obsidianmd/obsidian-api/blob/master/obsidian.d.ts). Сам факт использования API не заменяет нативную проверку.

Статус: подготовленная установочная сборка для локальной приемки. Публичная публикация не выполнялась.
