# Уточнения к ТЗ для Free 2.2.1

Дата: 7 октября 2026 года. Основа: ТЗ редакции 1.0 и последующий разбор замечаний.

1. Free содержит поиск, выбор проекта и сортировку по плановой дате/приоритету. Лимитов количества задач и проектов нет.
2. Перестановка внутри одного списка меняет только порядок. При переносе между списками применяется правило целевого списка. Восстановление через отдельную команду сохраняет плановую дату.
3. Today разделен на сворачиваемые группы просроченных и сегодняшних задач. Done отображает историю порциями по 50, без удаления старых задач.
4. Расчет продолжения серии использует исходный календарь и дату экземпляра по расписанию. Досрочное завершение не повторяет тот же плановый экземпляр. Невыполненные задачи не сдвигаются автоматически.
5. Очистка даты у повторяющейся задачи не добавляет отдельное состояние паузы. Правило сохраняется; следующее повторение создается после завершения.
6. История хранится отдельными Markdown-файлами. Восстановленный экземпляр с созданным продолжением становится разовым и при переносе, и через команду восстановления.
7. Поля `id`, `mptSeriesId`, `mptAnchor`, `mptScheduled`, `mptPreviousId`, `mptNextId`, `mptNextPending`, `completedAt` обеспечивают связь и восстановление повторений. Старые неизвестные поля сохраняются. Маркеры новой модели добавляются при действиях пользователя, без массового обновления файлов при запуске.
8. Резервная копия делается перед первым изменением файла в этой редакции. Проекты переименовываются без изменения пути. Архив и завершение остаются независимыми признаками.
9. Для изменения положения карточки на другую дату доступны меню и форма. Отдельного селектора состояния в форме нет: завершение и восстановление выполняются явными действиями карточки.
10. Настройки расширенной версии сохраняются в data.json, но не управляют Free. Ссылка на Pro отсутствует до появления заданного адреса сайта. Автоархивация, календарь и редактор произвольных списков не выполняются и не показываются.
11. Цель совместимости — публичный API Obsidian 1.6.6+. Нативная матрица платформ остается непроверенной. Замеры в тестовых объектах не заменяют требование 2 секунд / 300 мс на реальном компьютере.

Задание на публичную публикацию в каталоге, выбор лицензии распространения и создание сайта в эту поставку не входят.

## Дополнение по локализации 2.2.1

Поддержаны ru, en, es, de, pt-BR, fr. Язык задается автоматически по Obsidian или вручную с сохранением выбора. Региональные варианты сводятся к поддерживаемому языку; португальские варианты — к pt-BR. При неизвестном языке и недостающем переводе используется английский. Даты отображаются через Intl.DateTimeFormat, хранятся в ISO. Пользовательский текст не переводится. Минимальная версия API не изменена: новое getLanguage вызывается только при наличии функции, иначе используется резервный способ определения.
