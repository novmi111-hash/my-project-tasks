# My Project Tasks Free 2.2.1

Установочная Free-сборка с дополнительными языками на основе Free 2.2.0. Интерфейс упрощен, логика повторений переработана с сохранением истории. Данные остаются в Markdown-файлах хранилища Obsidian. Интернет, регистрация и лицензия не требуются. Задачи и проекты не ограничены по количеству.

## Установка и обновление

1. Для первой проверки используйте копию рабочего хранилища. Нативный запуск этой сборки в Obsidian пока не проверен; автоматизированные проверки описаны в TEST_REPORT.md.
2. Отключите прежний My Project Tasks в настройках Obsidian. Сохраните копию папок Tasks, Projects и `.obsidian/plugins/my-project-tasks` (если пути переопределены, используйте свои папки).
3. Из папки `my-project-tasks` этого архива скопируйте **main.js, manifest.json и styles.css** в `<ваше хранилище>/.obsidian/plugins/my-project-tasks/`, заменив одноименные файлы.
4. **Не удаляйте data.json**: в нем сохраняются прежние пути и настройки. Не копируйте всю папку релиза вместо папки плагина. Если каталог конфигурации хранилища отличается от `.obsidian`, используйте его.
5. Включите My Project Tasks Free. Откройте доску значком с галочкой на боковой панели или командой Open My Project Tasks Free.
6. Выберите язык в настройках плагина: Русский, English, Español, Deutsch, Português (Brasil) или Français. Новые папки Tasks и Projects создаются при необходимости.

Идентификатор плагина сохранен: `my-project-tasks`. Free заменяет прежнюю сборку в том же каталоге. Одновременная установка двух редакций с этим идентификатором не предусмотрена.

## Язык интерфейса

Выбор находится в Настройки → My Project Tasks Free → «Язык / Language». Режим «Автоматически» использует язык Obsidian. В старых версиях применяется прежняя настройка языка; если она недоступна — язык устройства. Неизвестный язык дает английский интерфейс. Региональные варианты распознаются: es-MX → Español, de-AT → Deutsch, pt / pt_BR / pt-PT → Português (Brasil), fr-CA → Français. Португальская локализация в этом выпуске только бразильская.

Вручную выбранный язык сохраняется между перезапусками. Переведены формы задач и проектов, меню, подтверждения, сообщения плагина и команды. Названия проектов, задач, описания и пользовательские данные не переводятся.

| Язык | Пример даты 7 октября 2026 года |
| --- | --- |
| Русский | 07.10.2026 |
| English | 10/07/2026 |
| Español | 07/10/2026 |
| Deutsch | 07.10.2026 |
| Português (Brasil) | 07/10/2026 |
| Français | 07/10/2026 |

Формат хранения остается YYYY-MM-DD. Поле ввода даты использует штатный элемент Obsidian/браузера, поэтому его визуальный формат может зависеть от языка системы. При недостающем переводе отдельной строки используется английский.

Каталог резервных копий Free-2.2.0 сохраняется и в 2.2.1: обновление языков не начинает новую миграцию данных. Переводы не проходили независимую проверку носителями языка.

## Что доступно

- Бэклог, Сегодня, Выполнено; проекты с цветами; три приоритета.
- Название, описание, одна плановая дата, чек-лист.
- Поиск по названию, описанию и чек-листу; выбор проекта; сортировка по дате, приоритету или вручную.
- Drag & drop, кнопки и меню карточки; перенос на сегодня, в бэклог, на следующий день; завершение и восстановление.
- Отдельные сворачиваемые группы «Просрочено» и «На сегодня». В Выполнено сначала последние записи; история загружается по 50 карточек.
- Ежедневные, еженедельные и ежемесячные повторения.
- Шесть языков интерфейса; стили используют цвета темы Obsidian.
- Открытие Markdown-файла задачи и ранее сохраненной исходной заметки через меню.

Week/Month, произвольные списки, календарь, отдельный архив и дедлайн не показаны. Старые значения этих полей и старые настройки остаются в файлах. Автоархивирование выключено в логике Free независимо от прежней настройки.

## Даты и повторения

Незавершенные задачи с сегодняшней или прошедшей датой находятся в Сегодня. Будущие задачи и задачи без даты — в Бэклоге. Просроченная дата не меняется автоматически.

Перенос между списками: в Сегодня — дата сегодня; в Бэклог — дата очищается; в Выполнено — сохраняется плановая дата и отдельно записывается дата завершения. Изменение порядка внутри одного списка дату не меняет. Кнопка «Вернуть в работу» сохраняет плановую дату и выбирает список автоматически. Перетаскивание из Выполнено применяет правила выбранного целевого списка.

Повторение создает следующий экземпляр только после завершения текущего. Выполненный экземпляр остается в истории. Следующая дата строго позже исходной даты экземпляра по расписанию и фактического дня завершения. Пропущенные периоды не создают пачку задач. Ежемесячный повтор от 31 января проходит через последний день февраля и возвращается на 31 марта.

Перенос даты вручную не изменяет календарь серии. Очистка даты снимает плановую дату текущего экземпляра, но сохраняет правило; при завершении следующая дата рассчитывается по исходному расписанию. Изменение вида повторения у активной задачи задает новый календарь от указанной даты. В истории правило повторения не редактируется. Восстановленный экземпляр с уже созданным продолжением становится разовым, чтобы не создавать вторую серию.

Удаление активного экземпляра останавливает продолжение серии. Удаление истории не удаляет активную задачу. Чек-лист следующего экземпляра копируется без отметок выполнения.

При ошибке создания следующего экземпляра на завершенном файле сохраняется служебная запись. Открытие доски повторяет операцию, не создавая вторую копию уже записанного продолжения.

## Сохранность данных

При запуске не выполняется массовая миграция. Перед первым изменением каждого файла в этой редакции создается JSON-копия в `MyProjectTasksBackups/Free-2.2.0/`. В ней находятся `originalPath` и исходный текст `content`. Резервные копии не распознаются плагином как задачи.

Сохраняются значения неизвестных свойств, включая вложенные данные. При записи YAML может быть переформатирован, а комментарии в YAML не сохраняются; исходный текст находится в резервной копии. Обычный текст заметки сохраняется, если пользователь не меняет описание. Измененная извне заметка не перезаписывается устаревшей открытой формой: требуется открыть форму заново.

Проект переименовывается в поле имени, а путь его Markdown-файла остается прежним, поэтому связи задач сохраняются. При удалении проекта задачи сохраняются без проекта; перед удалением показывается их количество. Удаление использует корзину Obsidian.

Архивный признак сам по себе не означает завершение: старые завершенные архивные задачи показаны в Выполнено, незавершенные — по дате, с отметкой об архиве.

## Совместимость и ограничения проверки

В manifest указан минимальный уровень Obsidian 1.6.6. Используется публичный API Obsidian; прямых файловых вызовов Node.js в плагине нет. Однако установка на конкретную версию Obsidian и устройства Windows/macOS/Linux/Android/iOS в этой среде не выполнялась. Поддержку этих платформ нельзя считать подтвержденной тестами.

Не подтверждена конфликтная синхронизация при одновременном завершении одной серии на разных устройствах. После синхронизации изменения файлов перечитываются; защита от повторного нажатия действует внутри одного процесса плагина.

Для отката используйте полный снимок хранилища перед обновлением вместе со старой сборкой. Не запускайте 2.1.5 поверх уже измененной истории Free: прежняя логика может перепланировать завершенные повторения. Автоматические JSON-копии содержат исходные версии отдельных измененных файлов, а не полный снимок всего хранилища.

## Содержимое пакета

- `my-project-tasks/` — три файла для установки.
- `src/` — исходный код.
- `tests/` — проверки с тестовыми реализациями API и DOM.
- `build.cjs` — сборка без дополнительных npm-зависимостей: `node build.cjs`.
- `TEST_REPORT.md`, `TEST-RESULTS.txt`, `PERFORMANCE.json` — результаты и границы проверки.
- `RELEASE_SPEC.md` — уточнения требований, реализованные в сборке.
- `README_EN.md` — инструкция на английском.

Проверки: `node --test tests/*.test.cjs`. Тесты требуют Node.js 18 или новее. Пакет подготовлен для ручной установки; публикация в каталоге Obsidian и на сайте продаж не выполнялась.
